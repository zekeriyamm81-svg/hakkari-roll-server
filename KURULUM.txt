HAKKARİ ROLL V5 — KISA KURULUM

YEREL ÇALIŞTIRMA
1. Python 3.11 veya daha yenisini kur.
2. Proje klasöründe: python -m venv .venv
3. Windows: .venv\Scripts\activate
4. Bağımlılıklar: pip install -r requirements.txt
5. .env.example içindeki değişkenleri kendi ortamına ekle.
6. Başlat: python hakkari_roll_server.py
7. Aç: http://127.0.0.1:5000

RAILWAY KURULUMU
1. Bu klasörün içeriğini yeni bir GitHub deposuna yükle.
2. Railway > New Project > Deploy from GitHub ile depoyu seç.
3. Servise bir Volume ekle ve /data yoluna bağla.
4. Aşağıdaki Variables değerlerini oluştur:

   HAKKARI_ROLL_ENV=production
   HAKKARI_ROLL_DB_PATH=/data/hakkari_roll.db
   HAKKARI_ROLL_UPLOAD_DIR=/data/uploads
   HAKKARI_ROLL_ADMIN_USERNAME=admin
   HAKKARI_ROLL_ADMIN_PASSWORD=BENZERSIZ_UZUN_BIR_PAROLA
   HAKKARI_ROLL_PEPPER=EN_AZ_32_KARAKTER_RASTGELE_BIR_DEGER
   HAKKARI_ROLL_TRUST_PROXY=1
   RESEND_API_KEY=...
   RESEND_FROM=Hakkari Roll <noreply@alanadiniz.com>

5. Deploy tamamlanınca /health adresinin ok=true döndürdüğünü kontrol et.
6. Yönetici parolasını ve pepper değerini kaynak koda yazma veya paylaşma.

ÖNEMLİ
- Railway Volume kullanılmazsa veritabanı ve yüklenen fotoğraflar deploy sonrasında kaybolur.
- Üretim modunda varsayılan admin parolası veya pepper ile uygulama başlamaz.
- SQLite kullanıldığı için Gunicorn tek worker ile çalışır; threads değeri eşzamanlı istekleri karşılar.
